# PR-001 — Remove Stale Hardcoded Models (P0)



### المشكلة



الكتالوج المحلي يحتوي نماذج لم تعد متوفرة في OpenRouter.



### الملفات



```

lib/ai-orchestrator/src/openrouter/model-catalog.ts

```



### الدليل



وجود:



```

deepseek/deepseek-v3-0324:free

```



بينما OpenRouter يرجع:



```

MODEL_NOT_FOUND

404

selected model is unavailable

```



### المطلوب



* إزالة جميع النماذج المتوقفة.

* استخدام النماذج المدعومة فقط.

* منع اختيار أي Model غير موجود.



### Acceptance Criteria



* لا يظهر MODEL_NOT_FOUND بسبب نموذج محلي.

* جميع Default Models موجودة فعلاً داخل OpenRouter.

# PR-003 — Treat Invalid Model as Recoverable (P0)



### المشكلة



الـ fallback يعمل فقط مع:



```

404

```



بينما:



```

400 invalid model id

422 selected model unavailable

```



لا يدخل fallback.



### الملفات



```

openai-compatible-client.ts

```



### المطلوب



اعتبار الحالات التالية:



```

400 invalid model



404 model not found



410 discontinued



422 unavailable



```



كلها:



```

MODEL_NOT_FOUND

```



### Acceptance Criteria



أي Model غير صالح ينتقل مباشرة للنموذج التالي.

================================================================================
JIRA EPIC
================================================================================

Epic Key:
AI-01

Title:
Decompose AI Orchestration Layer

Goal:
Reduce architectural complexity and improve maintainability of the AI orchestration layer without changing functional behavior or external APIs.

Definition of Done:
- Existing behavior is preserved.
- No functional regressions.
- Existing tests continue to pass.
- New tests added where applicable.
- Documentation updated where architecture changes.

================================================================================
PR-001
================================================================================

Title
Eliminate any from Context Loader

Status
Confirmed

Priority
Critical

Components
AI Orchestrator
Context

Description

The context loading boundary currently relies on several `any`-typed fields inside `LoadedProjectContext`, reducing compile-time guarantees and allowing runtime shape drift.

Replace untyped objects with explicit DTOs and strongly typed mapping.

Scope

- context-loader.ts
- LoadedProjectContext
- Typed DTOs
- Mapping layer

Acceptance Criteria

□ No `any` remains inside LoadedProjectContext
□ All database rows map into explicit DTOs
□ TypeScript passes without suppressions
□ Existing behavior unchanged
□ Unit tests updated

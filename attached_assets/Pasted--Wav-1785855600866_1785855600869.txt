## ملاحظة عملية أخيرة

الترتيب الأنسب للتنفيذ من هذه الخطة هو:

1. **Wave 0**: تثبيت السياسة التنفيذية.
2. **Wave 1**: إنشاء Context Runtime and admission.
3. **Wave 2**: cache/lifetime/delta.
4. **Wave 3**: prompt profiles + request assembly.
5. **Wave 4**: graph virtualization.
6. **Wave 5**: episode memory + replay-free runtime.

 تحويل هذه الخطة الآن إلى * **Patch-by-patch checklist** لكل ملف على حدة. من داخل الملفات المرفقة للمشروع ابدأ ب wave 0 فقط

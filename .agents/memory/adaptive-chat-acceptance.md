---
name: Adaptive chat acceptance
description: Durable acceptance rules for fallback planner and sub-query evidence tests.
---

Adaptive planning acceptance must exercise the real `chat()` path, not only `scheduleSubQueries()` or `planQuery()`. The test must observe the server-owned fallback status, verify that each scheduled sub-query produces a bounded read in its own scope, force a missing read through the same execution path, and assert that incomplete claims remain blocked rather than becoming `PROVEN`.

**Why:** Planner-only tests can pass while chat skips hierarchical execution, reuses an unintended prefetch cache, or lets a provider's synthesis claim outrun missing evidence.

**How to apply:** Use disposable filesystem fixtures and deterministic provider strategies. Keep prefetch isolated when asserting sub-query reads, assert both bounded attempt counts and the final objective/diagnostic projection, verify that independent waves actually overlap while synthesis waits for every receipt, verify that dependent sub-queries are skipped when a prerequisite fails, preserve completed evidence and stop wave advancement when cancellation arrives between sub-queries, inspect `SCHEDULING_WAVE_STARTED` for independent waves, confirm independent siblings continue after one source fails, test transitive dependency cascades alongside a successful second-wave sibling, validate mixed retained/missing sibling evidence, ensure failed-receipt diagnostics reach synthesis only as a non-evidence placeholder, reject FACT claims about failed sub-queries, bound provider synthesis failures and synthesis tool-call attempts without replaying completed sub-queries, validate every compound coverage part after synthesis, preserve retained evidence when synthesis is cancelled, and reject provider citations outside retained evidence without echoing their paths in user-facing output. A read attempt before provider failure is not retained evidence unless the execution result explicitly preserves it. Proof-required objective-gate tests and adaptive hierarchy tests should remain separate because objective turns may bypass the hierarchical early-return path.

---
name: Project-query proof reads
description: Why proof-required targeted project queries must carry source evidence into final acceptance.
---

Proof-required `PROJECT_QUERY` executions must promote their server-owned proof contract into the source-evidence requirement before the provider/tool loop and terminal acceptance are assembled.

**Why:** Some natural-language project questions resolve to a targeted objective and claims while the raw intent classifier still marks evidence as optional. Without this coupling, analysis evidence can validate successfully but final acceptance receives no retained reads and is rejected as incomplete.

**How to apply:** When adding or changing project-query proof/resume routing, derive source-read requirements from the persisted `PROJECT_QUERY` proof contract as well as the raw intent, while keeping unrelated delivery/build proof paths unchanged.

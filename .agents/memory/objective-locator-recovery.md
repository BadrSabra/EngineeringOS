---
name: Objective locator recovery
description: Constraint for recovering bounded evidence windows when a later required source read is truncated
---

For a declared objective, bounded evidence recovery must have a server-owned locator for every required evidence path before relying on a provider-selected read. A first-evidence prefetch for only one path is insufficient: a later full read can be truncated, leave no retained body, and make the bounded window unavailable even when the source contains valid claim needles. Once a usable locator exists, a later truncated provider result must never replace it. Claims spanning multiple files must also declare path-scoped needles; applying every symbol to every path makes valid bounded windows impossible. Needles in one file must share a bounded executable cluster, or the claim needs separate path/edge windows; import-level and far-away result-variable needles can otherwise reject recovery before dispatch. The same applies to runtime-edge proof: a complete targeted window is not enough when the verifier requires the caller's function body; each required edge needs a server-owned full caller body plus a retained read from that caller file.

**Why:** Embedded-AI audits have failed both when a later source path had no locator and when declared needles were too far apart to form one bounded window. A valid locator can also be lost if a truncated provider read overwrites the locator map. All three cases stop evidence acquisition before `read_file_range`; they are evidence-acquisition failures, not acceptance or identity failures.

**How to apply:** Before or at the first truncated read of each required path, obtain server-owned locator data (prefer bounded line discovery over accepting a full body), validate that the needles have a bounded executable cluster, then dispatch only the computed `read_file_range` window into accepted evidence. Merge locator updates monotonically: replace a locator only with another usable locator, never with a truncated/failed result. For reachability edges, use the server-owned full body only to bind the caller AST and direct call, and require a retained read from the same caller file before closing the edge. Keep locator data separate from retained/accepted proof and preserve the no-head-fallback rule.

---
name: Gap query routing
description: Routing boundary for analytical weakness and gap questions.
---

Gap and weakness questions are proof-backed `PROJECT_QUERY` turns, not ordinary low-risk chat and not automatically broad forensic audits.

**Why:** A generic question such as “What are the agent's weaknesses?” can be classified as a simple/code question before the gap signal is considered. That lets a provider answer without the required target, source manifest, or semantic acceptance.

**How to apply:** Keep the low-risk fast path explicitly excluded for gap signals, and preserve the targeted `gap-analysis` objective so the required source paths and claims remain server-owned. Broad-review consent still applies separately to requests that explicitly ask for a whole-project audit.

# تحقق إغلاق مصدر مهلة إعادة المحاولة في مسارات AI

التاريخ: 2026-11-01

## الحكم

أُغلقت فجوة **نسبة مصدر المهلة داخل التطبيق** في Chat المتدفق وغير المتدفق وسجل المحادثة. لم تُحل قيود سعة الحصة المجانية المشتركة لدى OpenRouter، ولم تُثبت رحلة استدلال حيّة. لذلك قد يستمر `RATE_LIMITED` عند نفاد الحصة، ولا يعني هذا التغيير أن `EMPTY_RESPONSE` قد اختفى.

## الفجوات التي عولجت

- كان العرض يخلط بين مدة انتظار محلية وبين `Retry-After` من المزود، كما أن رسالة الجاهزية تقترح سابقًا الانتقال إلى مزود آخر.
- كان عميل SSE لا يحفظ مصدر المهلة في بعض ردود HTTP التي تصل قبل بدء SSE، أو عند إعادة تحليل حدث SSE؛ أضيفت قائمة سماح للمصادر المعروفة ويُحذف المصدر غير المعروف.
- كان `POST /api/ai/chat` غير المتدفق يحفظ مدة الانتظار ونطاق التقييد دون مصدرها، كما لم يتضمن رد JSON هذا المصدر.
- صار الرد غير المتدفق، وإطار SSE، وإسقاط سجل المحادثة يميزون بين مهلة المزود والتبريد المحلي. لا يُستنتج أن المهلة من المزود لمجرد وجود مدة.
- أزيلت إرشادات الواجهة التي تطلب اختيار مزود آخر؛ لا يوجد تحويل تلقائي إلى مزود أو نموذج مدفوع.

تعتمد النسبة على `resolveAiRetryAfterSource`: لا تُنسب المهلة إلى المزود إلا عند وجود مدة موجبة مع حالة 429 صريحة؛ رموز التبريد المحلي المعروفة تبقى محلية؛ وإذا تعذر تحديد المصدر فيظل مجهولًا.

## التحقق المنفذ

| الفحص | النتيجة |
|---|---:|
| `AiChat.authenticated.test.tsx` | 252 ناجحًا |

| `ai-terminal-outcome.test.ts` | 29 ناجحًا |
| `ai/chat-sse.test.ts` كاملًا | 57 ناجحًا |
| اختبار تحليل API المحدد | 1 ناجح، 216 متجاوزًا |
| TypeScript للـDashboard وAPI server | ناجح |
| `git diff --check` | ناجح |

اختبارات API التي تحتاج قاعدة بيانات استخدمت PostgreSQL مؤقتًا على loopback، مع `DATABASE_URL` صريح، وفحص `SELECT 1`، وتطبيق مخطط Drizzle على القاعدة المؤقتة وحدها، ثم إيقافها وتنظيف جذرها المؤقت. شُغّلت اختبارات المسارات مع `AI_PROVIDER_EGRESS_DISABLED=1`، وكانت استدعاءات النموذج محاكاة؛ لم يُرسل طلب استدلال حي إلى OpenRouter.

أُعيد تشغيل سيرفري API وDashboard بعد التغييرات. سجل API يثبت بدء الخدمة على المنفذ 8080؛ وسجل Vite يثبت جاهزية Dashboard على `/dashboard/`. أثناء بدء API سُجل تحديث فهرس النماذج المجانية (17 مجانيًا و0 مدفوع في الإسقاط المسجل)، وهو تحديث بيانات فهرس لا استدلال نموذج.

## الحدود المتبقية

- لا يمكن للكود المحلي زيادة الحصة المشتركة التي يحددها OpenRouter أو ضمان توفر النموذج المجاني في وقت لاحق.
- لم يُنفذ اختبار حي، لذا لا يوجد دليل جديد على نجاح الاستدلال عند عودة الحصة، ولا على زوال `RATE_LIMITED` أو `EMPTY_RESPONSE` من جهة المزود.
- التحقق المرئي بتسجيل دخول حقيقي لم يُجرَ؛ تغطية الواجهة هنا باختبارات React، وتغطية API باختبارات تكامل معزولة.
- لم تُنفذ DDL على Development أو Production، ولم يُنشر التطبيق، ولم يُنشأ commit أو push.

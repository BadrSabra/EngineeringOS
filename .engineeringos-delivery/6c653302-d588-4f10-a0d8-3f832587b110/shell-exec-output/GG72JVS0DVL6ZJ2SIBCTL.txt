     1/**
     2 * PR-012 — Regression tests for the OpenAI-compatible client.
     3 *
     4 * Covers:
     5 *   • Gemini strips tools / response_format (existing)
     6 *   • 400 invalid model id → MODEL_NOT_FOUND + fallback (existing)
     7 *   • 404 → MODEL_NOT_FOUND + fallback (PR-003)
     8 *   • 410 → MODEL_UNAVAILABLE + fallback (PR-003)
     9 *   • 422 → MODEL_UNAVAILABLE + fallback (PR-003)
    10 *   • 429 rate-limit → RATE_LIMITED
    11 *   • 429 quota/credits body → QUOTA (PR-008)
    12 *   • 401/403 → AUTH_ERROR
    13 *   • 5xx → SERVER_ERROR
    14 *   • All fallback candidates exhausted → throws MODEL_NOT_FOUND
    15 *   • Provider error context preserved on error (PR-007)
    16 */

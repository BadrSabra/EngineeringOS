The apply path already records change-set, candidate, and promoted hashes, but candidate validation currently starts from the full proposal while partial approval can submit only a subset, live-root checks are limited to selected files, and Git commit relies primarily on event presence and per-file bytes. A single full-tree proof is needed to bind the exact authorized candidate to live promotion and the resulting commit.

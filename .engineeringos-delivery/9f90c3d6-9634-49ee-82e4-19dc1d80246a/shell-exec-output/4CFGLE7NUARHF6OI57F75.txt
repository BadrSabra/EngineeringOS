# Prevent retry history from disappearing after a reload

## What & Why
The dashboard now restores incomplete analysis and code-review attempts, but the API persistence contract is not directly asserted in the server test suite. A focused regression check will protect auditability when retry responses or session reuse change.

## Done looks like
- A server test forces a structured analysis or code-review failure and asserts the response returns a session ID.
- The persisted session contains the original prompt and a failed assistant message with the bounded structured-failure marker.
- A retry using that session ID preserves the earlier failed message instead of replacing it.

- Native OpenAI tool calls and the existing supported XML form continue to dispatch unchanged, with safe JSON-object arguments.

That leaves the full candidate tree → live promotion → commit relationship only partially proven, especially for partial approvals, unrelated root drift, and stale or incomplete apply evidence.
